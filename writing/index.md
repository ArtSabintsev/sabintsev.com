Essays by Arthur Sabintsev. Full text, no login. The same list is on the [homepage](https://sabintsev.com/#writing).

- [Zcash is Not Hard Money](https://sabintsev.com/writing/zcash-is-not-hard-money/) (June 8, 2026). Naval called ZEC insurance against Bitcoin. - [Your Token Was An Equity Grant All Along](https://sabintsev.com/writing/your-token-was-an-equity-grant-all-along/) (May 25, 2026). Customers want the work priced in dollars. Operators still hold the token for the upside. [Markdown](https://sabintsev.com/writing/your-token-was-an-equity-grant-all-along/index.md)
- [The Resilience Premium](https://sabintsev.com/writing/the-resilience-premium/) (May 22, 2026). A second vendor fails as a backup when it goes down for the same reason as the first. [Markdown](https://sabintsev.com/writing/the-resilience-premium/index.md)

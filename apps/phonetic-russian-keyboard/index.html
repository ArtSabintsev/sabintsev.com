Enable the keyboard

  1. Install Phonetic Russian Keyboard from the App Store.
  2. Open the app and follow Setup, or go to Settings → General → Keyboard → Keyboards → Add New Keyboard…
  3. Choose Phonetic Russian under the Phonetic Russian Keyboard app.
  4. In any text field, tap the globe key and select Phonetic RU.

With a hardware keyboard (or in Simulator), press ⌘K to show or hide the software keyboard.

What this keyboard is

  • Phonetic: one key → one letter by sound (ЯВЕРТЫ sticker map).
  • Cyrillic-only faces so Latin-keyboard users can type Russian without learning ЙЦУКЕН.
  • Not Windows Russian Mnemonic multi-key combos, and not multi-letter transliteration.

Privacy

Fully on-device. No Full Access, no network, no analytics, no keylogging. Full text: privacy policy.

Common questions

I installed the app but don’t see the keyboard
The App Store app is the setup host. Add the keyboard under Settings → General → Keyboard → Keyboards, then pick Phonetic RU with the globe key.
Does it need Full Access?
No. Leave Full Access off. Typing stays on your device.
Does it collect what I type?
No. Typed text is only inserted into the active field on your device.
